Bring Faerie into a workspace +

Faerie can guide attention to any element, visit a point on the screen, speak, follow, or quietly rest. The workspace decides when she helps.

import { createFaerie } from '../src/index.js';

const faerie = createFaerie({ tone: 'moonlight' });

faerie.attend(document.querySelector('#next-step'), {
  message: 'Your next small step is right here.',
  action: { label: 'Got it', onSelect: () => faerie.rest() }
});

This playground stands on its own. Faerie isn’t attached to an app.
