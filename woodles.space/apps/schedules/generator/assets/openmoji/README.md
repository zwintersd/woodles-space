# OpenMoji artwork

These unmodified SVGs are copied from Woodles' Bloomforge OpenMoji bundle,
which was sourced from the `color/svg` set in `openmoji@17.0.0`. They are used
to give schedule symbols the same artwork across platforms.

All emojis designed by [OpenMoji](https://openmoji.org/) — the open-source
